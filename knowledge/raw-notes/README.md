# Raw Notes

Raw Notes preserve public-safe observations, practitioner reasoning, hypotheses,
solution trade-offs, generalized cases, and disclosure notes before validation.

They are intentionally allowed to be incomplete, contradictory, duplicated, or
incorrect. They are prohibited in Production Architecture Review.

Use `schemas/raw-note-template.md`.

Suggested subdirectories:

- `practitioner-reasoning/`
- `solution-lenses/`
- `generic-cases/`
- `disclosures/`

Create a subdirectory when the first note of that kind is added; empty
classification directories are not required.
