# Curated Failure Model

The Failure Model is the repository's first curated knowledge product.

It contains Success Criteria, Symptoms, and Root Causes connected through the
canonical causal vocabulary in `schemas/failure-model/node-spec.md`.

Existing nodes predate the maturity metadata introduced by IS-001. They are
treated as `legacy-curated` only through the explicit path, ID, filename, and
type compatibility rules in `policies/retrieval-policy.md`. Do not bulk-add
`maturity: curated` or `review_usage: allowed` without content review.
