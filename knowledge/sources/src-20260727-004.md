# Source Anchor

## Relevant Material

The researcher describes a YouTube Video Builder request that included a
caller-controlled Channel ID. Replacing that value with a Channel ID not owned
by the caller caused the server to upload an unlisted video to that Channel.

The disclosure reports the observable behavior, report timeline, and fix. It
does not disclose enough internal architecture to identify whether the missing
Ownership check resulted from Rule duplication, stale Integration logic,
client-side trust, or another implementation mechanism.

## Verification Use

Use this source to verify the observed missing object-level Authorization on the
Video Builder upload path.

Do not use it as proof that YouTube duplicated Business Rules between a Backend
and Integration Layer. That explanation remains a practitioner Architecture
hypothesis.
